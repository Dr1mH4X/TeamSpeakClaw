# AGENTS.md — Agent Notes

Agent Note 是 agent 写下的 RFC：记录决策与提案的为什么、放弃了什么、代价与验证方式。写或改本目录任何文件前，先读 [README.md](README.md) 的布局、分类与文件内格式，以及 [docs/AGENTS.md](../../docs/AGENTS.md) 的写作规则。

**每新增一篇笔记都要做取代性检查**：在活跃树里搜索覆盖同一决策、机制或被否决方案的旧笔记，把完全取代的 implemented 笔记在同一个 PR 里归档或删除，部分取代的保留并互相链接。不要在事后单独做一次语料清理。

[`archived/`](archived/AGENTS.md) 下的文件是冻结的历史快照：不要编辑，也不要当作当前行为的权威依据。
