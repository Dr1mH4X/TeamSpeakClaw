# AGENTS.md — 归档的 Agent Note

归档目录下的笔记是冻结的历史快照，不是当前行为的权威依据。不要编辑、重新格式化、翻译、修复、删除或移动已封存的文件；新的决策与事实写在活跃笔记或当前文档里。

归档一个变更只允许：把整篇文件从 `implemented/{class}/` 移到 `archived/{class}/`、在 `Status: implemented` 下方插入一行 `Archived: YYYY-MM-DD`、修复或删除指向它的入站链接。正文其余部分一字不改。

不要从归档笔记向外核查或修复链接：那些链接属于它被写下时的仓库状态。

本仓库没有归档校验脚本（无 TypeScript 工具链），封存后不再改动这件事靠人工保证。
