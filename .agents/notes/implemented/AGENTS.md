# AGENTS.md — 已落地的 Agent Note

这些笔记描述已经交付的决策。遵循[笔记规则](../AGENTS.md)（含[文件内格式](../AGENTS.md#文件内格式)）与 [docs/AGENTS.md](../../../docs/AGENTS.md)。

## 与实际交付的内容保持同步

代码后续改了路径、符号、默认值或机制时，在同一个改动里就地改写笔记里的事实，不要追加变更历史。

当一篇已落地笔记的决策已经完整落地、其依据不太可能再指导未来工作时，按[归档与删除](../AGENTS.md#归档与删除)的判据把它移入 [`../archived/`](../archived/AGENTS.md)，而不是继续维护。

## 这不是改写决策的许可

就地更新的是事实，不是决策。推翻决策或其依据必须新写一篇笔记并互相链接；被完全取代的旧笔记只有满足[合并规则](../AGENTS.md#何时需要写一份)时才能删除。
