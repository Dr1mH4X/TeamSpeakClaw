# 0.6.4 (2026-10-18): 联网搜索、网页抓取与终端界面

这一版补齐联网搜索的 Parallel 服务与网页正文抓取，把搜索和抓取结果统一按外部不可信数据处理；终端新增交互式活动区与状态栏，回答中的来源链接改为按用户要求才输出。

## 新增

- `web_search` 可在 `[web_search]` 中选择 Exa 或 Parallel，Parallel 走匿名 MCP，只接受查询语句（#106）。
- 新增 `web_fetch` 工具，抓取指定公网 HTTP(S) 页面并转换为 Markdown，只跟随同源重定向（#107）。
- 终端新增启动、连接、回合与工具活动区及状态栏，`--ui auto` 在交互终端启用、非交互输出回退为普通日志（#108）。

## 修复

- 搜索结果与抓取正文统一标注为外部不可信数据，并对来源、长度和控制字符设限，降低网页内容被当作指令的风险（#107）。
- 回答中的来源链接改为仅在用户明确要求时输出，搜索结果末尾不再附带引用指令。

## 优化

- rich 界面的控制台输出按行写入活动区，`--ui plain` 保留普通日志输出，文件日志不受影响（#108）。

## 其他

- Release 标题固定为 `Release <tag>`，发版日志首行继续校验版本、日期与简述。
- GitHub Actions 的常用 action 升到支持 Node 24 的版本，CI 的 push 与 PR 路径过滤统一为同一份构建输入清单。
- 网站补充联网搜索与网页抓取配置说明，网站依赖管理改用 pnpm；示例配置加入 `[web_search]` 并调整日志段位置。
- 修正 0.6.3 发版日志中 Release 标题来源的表述。

## 升级注意

- 想使用 Parallel 搜索时，在 `config/settings.toml` 增加 `[web_search]` 并设置 `provider = "parallel"`；保持默认 `exa` 则无需改动。
- `web_fetch` 需要单独授予 ACL 权限；示例配置中只有管理员的 `*` 覆盖它，普通用户组要显式加入 `allowed_tools`。
- 依赖交互终端日志输出或需要旧式控制台日志时使用 `--ui plain`；文件日志不受界面模式影响。
- 如果你依赖网页工具自动附上来源链接，需要在提问中明确要求来源；默认回复不会输出 URL。
