# 0.6.5-beta (2026-10-19): 预构建 Alpine 产物与 Debian 发布包

这一版调整发布构建链：Docker 镜像改为下载预构建的 Alpine/musl 二进制后组装，Linux 发布包拆分为 Ubuntu 与 Debian 两个归档；运行镜像仍是 `alpine:3.20`，程序行为没有变化。

## 新增

- 新增 `TeamSpeakClaw-v0.6.5-beta-Debian-amd64.tar.gz`，面向 Debian/glibc 用户。

## 优化

- Docker 不再在容器内编译 Rust，改为下载内部 Alpine/musl artifact 并用运行层 Dockerfile 组装，缩短镜像构建时间。

## 其他

- 原来的 Linux 发布包更名为 `TeamSpeakClaw-v0.6.5-beta-Ubuntu-amd64.tar.gz`。
- Alpine/musl 构建产物只作为 Docker 的内部 artifact，不进入 GitHub Release 附件；Ubuntu、Debian、Alpine 的构建缓存彼此隔离。

## 升级注意

- 下载脚本或文档如果写死了 `linux-amd64`，需要改用 `ubuntu-amd64`；Debian 用户使用 `debian-amd64`。
- Docker 镜像的入口、配置目录和运行层依赖不变，仍基于 `alpine:3.20`。
