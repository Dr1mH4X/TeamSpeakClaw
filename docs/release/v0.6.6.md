# 0.6.6 (2026-11-20): OpenProtocol、Rust Opus 与TTS优化

接入OpenProtocol开放身份互认与斜杠命令发现协议，将 Opus 编解码迁移至纯 Rust 实现并补齐入站抖动恢复，同时改进 TTS 文本清洗、流式分句、声学衔接与插话立即停声，并修复网页嵌套表格展开和状态栏连接误报。

## 新增

- 接入基于 `PluginCommand` 的开放身份互认（`tsclient:identity`）与按需斜杠命令发现（`tsclient:commands`）协议：进出频道广播或响应探询时声明 `bot` 类型、`TeamSpeakClaw` 名称与版本，建连首次就绪另发跨频道单向公告，并在私信请求时随 `list_ack` 下发带有 `command_prefix` 的原生语音回放主命令（#110，#112）。
- 语音回放直呼命令同时支持 `!replay` 与 `/replay`（及对应中文别名），在私信触发时直接回放而无需经过模型推理（#110）。
- 在线成员列表与 `GetClientInfo` 暴露三态 `away`、`input_muted`、`output_muted` 与 `channel_commander` 状态，并从工具返回中剔除 `client_away_message` 文本（#110）。
- 音频编解码迁移至纯 Rust `rusty-opus` 实现，语音桥入站新增基于 `seq` 的轻量重排缓冲与 FEC/PLC 丢包恢复。

## 修复

- 引入播报代次机制：唤醒词插话、回合顶替与唤醒确认音立即丢弃出站队列和通道中的过期音频帧，补发 0 字节尾包并重置发送节拍器，使新语音立即起播，已取消的播报流跳过建流。
- TTS 合成前剥离 Markdown 行前缀、链接目标与裸 URL（保留链接文字）、行内格式符、不可读符号与孤立标点，并按清洗后的有效内容判定是否送音。
- 终端状态栏的语音桥连接指示改由服务、事件流与连接 actor 三者实时聚合就绪状态驱动，NapCat 连接状态随 WebSocket 生命周期更新，消除功能禁用或未就绪时的连接误报（#109）。
- `web_fetch` 渲染 HTML 表格时仅按直接父子结构收集行列，嵌套表格在所属单元格内展平为纯文本，并按 CSS 词法与声明优先级过滤 `hidden`、`aria-hidden`、`display:none` 及 `visibility` 隐藏元素（#109）。
- OpenProtocol对进房广播实施 2 秒防抖与失败单次重试，对单播回执施加按对端与动作隔离的冷却窗口（`announce` 10 秒、`query` 与 `list_req` 各 5 秒）和全局令牌桶限流，确保出站完整 `plugincmd` 命令严格小于 1024 字节（#110）。

## 优化

- 同一 TTS 流式回复内的多段音频复用单个 Opus 编码器，段间衔接加入 3 毫秒首帧淡入，短音频与流式输出不足一帧的残余尾部补零并做 5 毫秒淡出后发送 0 字节尾包收尾。
- 重构流式 TTS 分句器：区分首句（4/12 字）与后续句（6/28 字，上限 100 字）阈值，跳过代码块围栏，以 1 字符前瞻保护小数、版本号、英文缩写、时间、千分位与 URL 不被拆断，并按词界切分超长英文文本。
- OpenProtocol收发、限流与防抖底层交由 `tsclient-rs` 托管实现，精简本地适配器状态。

## 其他

- 移除 `audiopus`、`cmake` 与 `libopus-dev` 编译依赖，简化 Linux 本地构建、CI 与容器镜像编译；`tsclient-rs` 依赖升至 0.3.1。
- 升级 `website` 的 pnpm 间接依赖（`body-parser`、`follow-redirects`、`launch-editor`）（#111），补充开放协议、音视频架构与决策笔记文档，并更新 README。
