# AGENTS.md — 文档站

- 默认语言是 `zh-Hans`：`docs/*.md` 是唯一源文，`i18n/en/docusaurus-plugin-content-docs/current/` 下的同名文件是英文镜像；改一处必须在同一次提交里改另一处。
- 镜像是否同步按结构判断：行数、标题层级、列表项数、表格行数与源文一致，翻译只改文字不改结构；结构一旦分叉（多出或少掉一段），说明镜像落后。
- 界面文案同样分语言：导航与页脚在 `i18n/en/docusaurus-theme-classic/{navbar,footer}.json`，通用字符串在 `i18n/en/code.json`，文档与侧边栏标签在 `i18n/en/docusaurus-plugin-content-docs/current.json`。
- 侧边栏由 `sidebars.ts` 的 `autogenerated` 生成，新增 `docs/*.md` 无需登记；英文镜像必须同名同目录，否则英文站点缺页。
- 只写面向最终用户的内容：不写源码路径、内部实现与决策历史。配置键、默认值与合法范围必须与 `src/config/` 的实现一致，设置项增删同步 `examples/config/settings.toml` 与 `docs/configuration.md`（含英文镜像）。
- 依赖用 pnpm（`pnpm-lock.yaml` 为准，Node ≥ 20）：`pnpm install` 后 `pnpm start` 本地预览、`pnpm run build` 产出 `build/`（已 gitignore）；`package-lock.json` 也在库内，依赖变动时两者一起更新。
- 部署走 `.github/workflows/deploy-website.yml`（`website/**` 变更时构建并发布到 GitHub Pages）；Rust CI 的 `paths-ignore` 排除 `website/**`，改这里不触发 cargo 门。
